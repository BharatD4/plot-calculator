# Plot Details Calculator

Full-stack app: React (Vite + Tailwind + Leaflet) frontend, Node/Express + MongoDB backend.
Map pe click karke plot ke corners mark karo, area/perimeter/units turant milte hain.

## Structure
- `server/` — Express API, MongoDB models, Turf.js-based geo calculations
- `client/` — React app with interactive Leaflet map

See the step-by-step chat guide for exact commands to run this project.
